# PAN MVPA Microstructure Paper

This repository contains the RMarkdown analysis script for the manuscript: **“Greater moderate-to-vigorous physical activity is associated with more favorable cortical gray matter microstructure in late middle-aged and older adults.”**

The repository includes analysis code used to examine associations between objectively measured moderate-to-vigorous physical activity, mean daily step count, cortical volume, and cortical gray matter diffusion MRI measures in the Precision Aging Network Healthy Minds for Life study.

De-identified data are available through the Precision Aging Network data access portal:
https://precisionagingnetwork.org/access-pan-study-data-for-research/

This repository does not contain participant-level data. The analytic sample was derived from participants with usable diffusion MRI data and accelerometry recordings meeting the inclusion and quality-control criteria described in the manuscript.
